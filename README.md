# キャリアデザイン2026 第3回 共有課題

## 課題

1. このリポジトリをUbuntuへcloneする。
2. mainを元に、自分の学生番号を名前とするブランチを作成する。
3. code.txtに含まれるC言語コードの誤りを修正する。正しく動作したときの出力は `Hello GitHub` である。
4. 変更をcommitし、自分の学生番号のブランチへpushする。
5. GitHubで修正後のcode.txtを確認し、自分のブランチのURLとpush成功画面を提出する。

mainと他の学生のブランチは変更しない。この課題ではPull Requestの作成・mergeは行わない。詳しい操作と提出方法は第3回のゼミナール資料を参照する。
